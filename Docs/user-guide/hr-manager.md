# Guide Manager et Ressources Humaines

Bienvenue dans l'espace de gestion. Ce portail vous permet d'administrer votre équipe, de traiter les demandes RH, et de piloter votre stratégie avec des outils d'analyse prédictive.

---

## 1. Validation des Congés

Lorsqu'un employé soumet une demande de congé, vous recevez une notification (et un email si le système SMTP est configuré).

1. Rendez-vous dans l'onglet **Congés** depuis la barre de navigation.
2. Par défaut, la vue affiche les congés **En attente** (Pending).
3. Cliquez sur l'icône de vue (œil) ou directement sur la ligne de la demande pour voir les détails (dates, motif, solde restant de l'employé).
4. Vous pouvez choisir d'**Approuver** (coche verte) ou de **Refuser** (croix rouge) la demande.
5. Une fois traitée, l'employé reçoit une notification automatique.

> **Astuce Manager :** Si vous êtes un "Manager de Département" (et non un profil RH complet), vous ne verrez dans cette liste que les demandes des employés appartenant à votre propre département. Les équipes RH globales voient toutes les demandes de l'entreprise.

---

## 2. Le Tableau de Bord (Dashboard) et KPIs

Le tableau de bord est le centre névralgique de vos opérations. Il regroupe les indicateurs de performance clés (KPIs).

Vous y trouverez :
- **Vue d'ensemble des effectifs** : Nombre total d'employés actifs, répartition hommes/femmes, etc.
- **Taux d'absentéisme** : Calculé sur la base des congés pris par rapport au temps de travail théorique.
- **Évolution de la masse salariale**.
- **Répartition par départements**.

Les graphiques sont interactifs. Vous pouvez survoler les barres ou les secteurs pour obtenir des chiffres précis.

## 3. Intelligence Artificielle & Alertes de Churn (Turnover)

Smart-HR intègre un moteur de Machine Learning (IA) exclusif pour prédire le risque de démission d'un employé.

### Comment ça marche ?
Toutes les nuits, un algorithme analyse l'historique des employés (ancienneté, augmentation de salaire, jours de congés restants non pris, promotions récentes, etc.) et génère un **Score de Risque de Churn** allant de 0 à 100%.

### Agir sur les alertes
- Sur votre tableau de bord, un encart dédié met en évidence les **employés à haut risque** (score > 70%).
- Une alerte visuelle (pastille rouge ou orange) apparaît à côté du nom de l'employé dans l'annuaire.
- **Action recommandée :** En tant que RH ou Manager, si un employé clé affiche un risque élevé, planifiez un entretien de suivi ou étudiez ses récentes évolutions salariales pour désamorcer une potentielle démission.

## 4. Recrutement

Le module de recrutement vous permet de publier des offres et de gérer le vivier de candidats.

1. Allez dans **Recrutement > Offres d'emploi**.
2. Créez une nouvelle offre en définissant le titre, le département, le salaire proposé et la description.
3. Les candidats peuvent postuler directement.
4. Leurs candidatures arriveront dans la section **Candidatures** où vous pourrez les trier par étape (Reviewing, Interview, Accepted, Rejected).
