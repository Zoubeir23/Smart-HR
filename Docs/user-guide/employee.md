# Guide Employé

Bienvenue dans votre espace employé Smart-HR. Ce portail a été conçu pour vous donner de la visibilité sur votre parcours professionnel, vos congés et vos documents administratifs.

## Mon Profil

Votre profil regroupe vos informations personnelles et professionnelles. 

1. **Accéder au profil** : Cliquez sur votre nom ou votre avatar en haut à droite de l'écran, puis sélectionnez **Profil**.
2. **Informations affichées** :
    - Vos coordonnées (Email, Téléphone, Adresse).
    - Vos informations professionnelles (Département, Poste, Date d'embauche).
    - Votre salaire actuel.
3. **Mise à jour** : En tant qu'employé, votre profil est en **lecture seule**. Pour modifier une information (par exemple, suite à un déménagement), veuillez contacter votre département RH via le système de notification ou par email.

## Mes Congés

Le module de congés vous permet de planifier vos absences très facilement.

### Consulter son solde
Sur votre tableau de bord (Dashboard), une carte résume vos jours de congés restants. Vous pouvez également voir l'historique complet de vos demandes en naviguant vers l'onglet **Congés** dans le menu principal.

### Faire une demande de congé
1. Cliquez sur l'onglet **Congés** dans le menu de gauche.
2. Cliquez sur le bouton **Nouvelle Demande**.
3. Un formulaire apparaît. Remplissez les champs suivants :
    - **Type de congé** (Congé payé, Maladie, Maternité, Sans solde, etc.)
    - **Date de début** et **Date de fin**.
    - **Motif** (Optionnel pour les congés payés, mais souvent requis pour les absences exceptionnelles).
4. Cliquez sur **Soumettre**.

> **Note :** Votre demande passe au statut `En attente` (Pending). Un email automatique est envoyé à votre manager (ou au service RH) pour validation. Vous recevrez une notification dans l'application dès que la demande sera traitée.

## Mes Documents (Paie)

Smart-HR centralise vos fiches de paie pour que vous puissiez y accéder à tout moment de manière sécurisée.

1. Allez dans l'onglet **Documents** ou **Paie** (selon la configuration de votre entreprise).
2. Vous y verrez la liste de vos bulletins de salaire classés par mois et par année.
3. Cliquez sur l'icône de téléchargement pour obtenir une version PDF de votre fiche de paie.
