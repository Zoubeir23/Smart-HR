# Bienvenue sur la Documentation Smart-HR

Smart-HR est un Système d'Information des Ressources Humaines (SIRH) moderne, intuitif et doté d'intelligence artificielle pour simplifier la gestion quotidienne de votre entreprise.

Cette plateforme centralise toutes les informations et les processus RH, de la gestion des congés au recrutement, en passant par l'analyse prédictive.

---

## Comment utiliser cette documentation ?

Que vous soyez un nouvel employé cherchant à poser un jour de congé, ou un manager RH souhaitant consulter les indicateurs de performance, vous trouverez ici toutes les informations nécessaires.

La documentation est divisée en deux grandes sections :

### 1. Le Guide Utilisateur 📖
Destiné à tous les utilisateurs de l'application. Choisissez le guide correspondant à votre rôle :
- [**Espace Employé**](user-guide/employee.md) : Pour gérer votre profil personnel, vos absences et vos fiches de paie.
- [**Espace Manager / RH**](user-guide/hr-manager.md) : Pour la validation des congés de votre équipe, le recrutement et l'accès au tableau de bord (Dashboard).
- [**Administration**](user-guide/admin.md) : Pour la configuration initiale, la création des comptes et la gestion des départements.

### 2. La Documentation Technique 🛠️
Destinée aux développeurs et à l'équipe IT chargée de maintenir ou de déployer la solution.
- **Architecture Système** : Comprendre le fonctionnement entre l'API Django et le front-end React.
- **Déploiement Docker** : Instructions pour lancer l'environnement de développement localement.
- **Matrice RBAC** : Détail des règles de sécurité et des permissions par rôle.
